画面没出来 / 想接进自己的页面

1. 课件数据已 base64 内嵌在本 HTML 里，不需要额外放 .swf 文件，也不需要本地服务器，双击就能跑。运行环境 Ruffle 仍需联网获取，三个地址会自动依次重试，全失败时状态栏会红字提示。

2. 接到自己已有页面时，最简写法：

<script src="https://fastly.jsdelivr.net/npm/@ruffle-rs/ruffle@0.8.0/ruffle.js"></script>
<script>
  var p = window.RufflePlayer.newest().createPlayer();
  document.body.appendChild(p);
  p.style.width = "960px"; p.style.height = "640px";
  p.ruffle().then(function (core) { core.load({ url: "MoonPhases_gb.swf" }); });
</script>

3. 备用地址（替换上面的 src 即可，注意同时把 config.publicPath 换成同域名）：
https://gcore.jsdelivr.net/npm/@ruffle-rs/ruffle@0.8.0/ruffle.js
https://unpkg.com/@ruffle-rs/ruffle@0.8.0/ruffle.js

4. 原站还有繁体版（MoonPhases.htm）与其他语种，把 swf 换掉即可，用法完全相同。
